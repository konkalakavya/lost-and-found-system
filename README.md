# Lost and Found Management System

## 📌 Project Description
This is a web-based Lost and Found Management System that helps users report lost items and find them easily.

## 🚀 Features
- Add lost items
- View found items
- Simple user interface
- Responsive design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Structure
- index.html → Main page
- css/ → Styles
- js/ → Scripts
- pages/ → Additional pages
