About Lost & Found Management System

The Lost & Found Management System is a web application designed to help users report lost items and found items easily.

Users can report a lost item, submit found item details, search for matching items, and view records through the dashboard.

Features

  • Report Lost Items
  • Report Found Items
  • Search Items
  • Dashboard
  • Local Storage Support
